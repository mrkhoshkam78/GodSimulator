# GOD SIMULATOR — THE WORLD IS YOURS v1.0.1

## اصلاحات این نسخه
- تقویم: هر سال ۳۶۰ روز بازی، هر روز = ۳۰ ثانیه واقعی در سرعت ۱
- سن از روز تولد محاسبه می‌شود؛ پیری دسته‌جمعی روی فریم حذف شد
- مرگ پیری فقط پس از سن ۶۵ و رسیدن به طول عمر (۷۲–۹۶)
- توقف زمان سن و رویداد را متوقف می‌کند
- منوی جمع‌شونده دسکتاپ و Drawer موبایل
- آیکون‌های SVG یکپارچه
- گرید و پنل‌ها برای لمس و موبایل
