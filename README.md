# GOD SIMULATOR — خدای خود باشید
**نسخه 1.1.2** — نسخه ریسپانسیو موبایلی بهبود‌یافته

بازی شبیه‌سازی و نیرنگی فارسی که در آن سرنوشت تمدن‌ها را بر دوش دارید.

## ✨ ویژگی‌ها

- **۳۰ قدرت الهی** — برکات، نفرین‌ها، معجزات
- **شبیه‌سازی عمیق** — شغل، روابط، احساسات، ثروت، سن
- **اتاق دعاها** — پاسخ به دعاها و شکل‌دهی ایمان
- **رویدادهای جهان** — تاریخ زنده مداخلات شما
- **ذخیره/بارگذاری** — ابدی کردن آفرینش‌های خود
- **دو تم** — شب کیهانی و سپیدهٔ سینمایی
- **موسیقی تولیدشده** — Web Audio API
- **ریسپانسیو کامل** — بهینه‌سازی برای تمام اندازه‌های صفحه

## 📱 بهبودی‌های ریسپانسیو v1.1.2

### طراحی موبایل‌اول
- ✅ بازنگری کامل چیدمان موبایلی
- ✅ دکمه‌های دوست‌داشتنی برای تاچ (حداقل 44×44px)
- ✅ شبکه‌های بهینه‌شده برای صفحات کوچک
- ✅ تایپوگرافی سیال با clamp() برای مقیاس‌پذیری
- ✅ چیدمان تک‌ستونی در موبایل (< 960px)
- ✅ نوار کشو ناوبری

### نقطه‌های توقف
- **< 400px**: تلفن‌های بسیار کوچک
- **400px - 600px**: تلفن‌های کوچک
- **600px - 960px**: تلفن‌های بزرگ و تبلت
- **960px+**: رایانه و تبلت‌های بزرگ

### بهبودی‌های کلیدی
1. **تاپبار**: فاصله بهتر، نمایش زمان ریسپانسیو
2. **نوار کنار**: لایه روپوش صاف‌تر با انتقال‌های هموار
3. **شبکه افراد**: مقیاس از ۱ ستون تا ۴+ در رایانه
4. **کارت قدرت**: اندازه ریسپانسیو، هدف تاچ بهتر
5. **مودال‌ها**: عملیات منطقه محفوظ، محتوای قابل پیمایش
6. **فرم‌ها**: فونت حداقل ۱۶px برای جلوگیری از زوم iOS
7. **دکمه‌ها**: تمام عناصر تعاملی اکنون > ۴۴px ارتفاع
8. **نوار نسخه**: اضافه‌شده زیر دکمه شروع (کوچک، محو)

### پشتیبانی دستگاه
- iOS 12.2+
- Android 5.0+
- مرورگرهای مدرن (Chrome، Firefox، Safari، Edge)
