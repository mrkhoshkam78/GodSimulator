# GOD SIMULATOR — THE WORLD IS YOURS v1.0

بازی مرورگری شبیه‌سازی خدای جهان. فایل `index.html` را در مرورگر باز کنید.

## فایل‌ها
- `index.html` — پوسته بازی و صحنه آغازین
- `css/style.css` — تم کیهانی، کارت‌ها، اتاق دعا، قدرت‌ها
- `js/data.js` — نام‌ها، مشاغل، ۳۰ قدرت، موضوعات دعا
- `js/utils.js` — ساخت انسان، مکالمه سه‌خطی، کمکی‌ها
- `js/save.js` — LocalStorage
- `js/simulation.js` — چرخه زندگی، ازدواج، تولد، مرگ، رویداد، دعا
- `js/powers.js` — پیاده‌سازی هر ۳۰ قدرت
- `js/ui.js` — گرید، پرونده، فیلتر، مودال قدرت
- `js/app.js` — ورود، زمان، ذخیره، تعامل

## قابلیت‌های پیاده‌شده
- ۲۰ انسان مستقل با مشخصات، احساسات، صفات، خاطرات و روابط
- گرید بدون نقشه جغرافیایی، کارت جمع‌شونده، جست‌وجو و فیلتر
- مکالمه سه‌خطی وابسته به حال فرد
- سیستم دعا با پنج حکم الهی و پیامد واقعی
- ۳۰ قدرت الهی با هدف فرد / گروه / جهان
- کنترل زمان (توقف، ۱×، ۳×، ۸×)
- شبیه‌سازی خودکار نیازها، شغل، ازدواج، تولد، مرگ
- تاریخچه جهان و مأموریت‌های اختیاری
- ذخیره خودکار و دستی؛ ادامه پس از Refresh
- رابط دسکتاپ و موبایل

## تست‌شده در ساختار کد
- جداسازی موتور از UI
- شناسه یکتا برای انسان‌ها و رویدادها
- قدرت احیا فقط روی فوت‌شدگان اثر کامل دارد
- دعا وضعیت و خاطره را به‌روز می‌کند
